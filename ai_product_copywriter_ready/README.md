# AI-помощник для товарных карточек

Локальный MVP на Python/FastAPI: принимает данные контрольно-измерительного прибора и готовит черновик B2B-карточки с помощью Gemini API.

## Возможности

- Веб-интерфейс и REST API.
- SEO-заголовок и описание, 3–5 поисковых запросов, коммерческий блок.
- Список недостающих данных и редакторские предупреждения.
- Экспорт результата в JSON и Markdown.
- Характеристики копируются из входного JSON — модель их не генерирует.
- При нарушении формальных требований выполняется одна корректирующая попытка генерации.

## Установка и запуск

Нужен Python 3.10+ и API-ключ Gemini из [Google AI Studio](https://aistudio.google.com/app/apikey).

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Укажите ключ и модель в `.env`:

```env
GEMINI_API_KEY=ваш_ключ
GEMINI_MODEL=gemini-3.5-flash-lite
```

Запуск:

```bash
python run.py
```

Интерфейс: http://127.0.0.1:8000  
Swagger: http://127.0.0.1:8000/docs

## API

`POST /api/generate` принимает JSON:

```json
{
  "name": "Манометр показывающий DM 02",
  "manufacturer": "Манотомь",
  "specs": {
    "диапазон измерений": "0–1,6 МПа",
    "класс точности": "1,5"
  },
  "description": "Прибор предназначен для измерения избыточного давления."
}
```

Для Markdown предусмотрен `POST /api/generate/markdown`. Примеры данных находятся в `examples/`.

## Промпты и принятые решения

Системный промпт задаёт роль технического B2B-копирайтера и ограничивает факты входным JSON. Пользовательский промпт передаёт товарные данные отдельно и запрещает воспринимать текст описания как инструкции. При ошибках формата второй промпт передаёт модели исходные сведения, предыдущий черновик и список замечаний для одной попытки исправления.

Ответ проверяется Pydantic-схемой и локальным валидатором. Python контролирует длину заголовка, длину SEO-описания, количество/повторы запросов и часть неподтверждённых чисел. Пустые характеристики нормализуются в «данных нет»; сама таблица всегда строится из входного `specs`.


## Тесты

```bash
pytest -q
```

Unit-тесты не требуют API-ключа. Они проверяют нормализацию входных данных, защиту характеристик, валидацию, корректирующую попытку и HTTP-обработку ошибок. Реальный вызов Gemini проверяется отдельно с действующим ключом.

## Ограничения и улучшения

Валидация чисел эвристическая и не выявляет все смысловые галлюцинации; перед публикацией карточку нужно сверять с паспортом. Если после одной корректирующей попытки SEO-описание всё ещё короче 800 символов, API возвращает понятную ошибку вместо карточки, нарушающей ТЗ. Слишком длинный заголовок и описание безопасно сокращаются с предупреждением.

Дальнейшие улучшения: проверка каждого утверждения по первоисточнику, извлечение фактов из PDF с указанием страниц, пакетная генерация, история версий и интеграция с CMS/PIM.
